# 考研专注养成

一只浮在桌面上的凤凰。你在浏览器里读 PDF，它就长大；你切到 B 站或知乎，它就打盹。
山巅是考试那天，海拔是你攒下的专注。

## 现在能做什么

- **桌宠**：透明、无边框、置顶的窗口，拖凤凰就能移动；点 `▾` 收起成一条药丸读数
  （状态圆点 + 今日计时），点 `⋯` 开菜单
- **反馈动画**：切走/超时凤凰会缩一下并飘出"扣 N 分钟"，切到学习外网站会摇头，
  回到专注会弹一下，进化与达标有扩散光环——只扣数字是"安静"的惩罚，感觉不到就改不掉
- **诚实计时**：前台是浏览器且不在学习外名单、且你 10 分钟内动过鼠标，才走表
- **三条惩罚**（都可配）：发呆超时扣 10 分钟；**每次从专注切走扣 1 分钟**（可改可关）；
  切到学习外网站额外记一次走神
- **养成**：凤凰 12 阶段（蛋 → 凤凰），形象随阶段变化；精神值调制明暗；
  连续天数与每月 2 张补签卡；升级/掉级与当日达标会弹托盘气泡
- **山**：山巅＝考试日，跟随累计专注推进；与"时间进度"对比出领先/欠账
- **统计**：今日 24 小时专注时间轴、走神热点（按小时聚合，标出峰值时段）、
  最近 30 天趋势、走神记录、总计
- **托盘**：暂停/显示隐藏凤凰/设置/统计/开机自启动/退出；关掉窗口不退出程序
- **开机自启动**：随 Windows 登录启动

## 怎么用

```bash
cd desktop
npm install          # 会从 npmmirror 拉 Electron 二进制（见 .npmrc）
npm start            # 开发态运行
npm test             # 全部单元测试（在仓库根跑）
npm run package      # 打包成 dist/KaoyanFocusCompanion-win32-x64/，可脱离开发环境运行
```

首次启动会自动打开设置页，填上考试日期与每日目标即可。

数据存在 Electron 的 userData 目录：`kaoyan-focus-state.json` 与排错用的 `kaoyan-focus.log`。

## 目录结构

```
src/core/     共享纯逻辑：时间切分、会话状态机、账户结算、成长与山（无浏览器/Electron 依赖）
src/lib/      共享纯逻辑：设置归一化、存储封装、快照组装
desktop/      桌宠本体（Electron）
  main.js       主进程：窗口、托盘、计时主循环、IPC
  src/*.mjs     可单测的纯逻辑：判定分层、文件存储、探针解析、样本映射、时段、自身进程识别
  native/       PowerShell 探针（只读 Win32）
  pet/ settings/ stats/   三个界面
  scripts/      托盘图标生成器
extension/    已退役的浏览器扩展形态（保留作参考）
test/ desktop/test/   单元测试
```

## 几个绕不过去的设计约束

**为什么不是浏览器扩展？** 内容脚本**无法注入 Edge 自带的 PDF 查看器**，
而本地 PDF 正是主场景——页面内浮层在那里完全不可见。画中画方案的窗口边框又由浏览器绘制、
CSS 碰不到。所以最终走原生窗口。

**为什么用常驻 PowerShell 做探针？** Electron 没有读前台窗口的 API。
原生 Node addon 要 node-gyp + MSVC 编译链；PowerShell 的 `Add-Type` 直接 P/Invoke Win32，
零编译依赖，实测可读中文窗口标题与系统空闲时长。探针只读，不发送输入、不改系统设置。

**为什么"标题为主、URL 可开关"？** 窗口标题是唯一稳定信号，但模糊（靠标题里带不带站名）。
UI Automation 能精确读到地址栏内容，代价是让 Edge/Chrome **常驻无障碍模式**（浏览器自身的
持续开销），且控件名与无障碍树随版本变化。所以默认用标题，精确模式做成可选开关，读不到自动回退。

**为什么要显式忽略自身进程？** 拖动或点击桌宠时前台会变成它自己。不忽略的话，
你每摸一下宠物，学习时间就断一次。名单必须**运行时**并入 `path.basename(process.execPath)`
——开发态是 `electron.exe`、打包后是 `KaoyanFocusCompanion.exe`，写死必然漏一个。


214 个用例，覆盖共享核心、判定分层、文件存储、探针解析、样本映射、时段合并与跨天切分、

## 已知限制

- 学习外判定靠窗口标题关键词，小众站点标题里若不含站名就认不出（可用精确模式或手动加关键词）
- 手机分心是桌宠覆盖不到的部分
- 精确模式尚未在真实浏览器上验证过
- 打包产物未签名，Windows 首次运行可能弹 SmartScreen 提示
