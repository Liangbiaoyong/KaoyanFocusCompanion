计分口径

「切走」指从专注状态切到别的程序或学习外网站，每切走一次从今日计时和成长值里一起扣 这么多，填 0 即关闭。为避免反复切窗口被连罚，两次扣分之间至少间隔上面这个时间 （窗口内再切走只提醒、不扣分）。发呆超时是另一条规则（固定扣 10 分钟），不与此叠加。

开启后 Chrome / Edge 会常驻在无障碍模式下（浏览器自身的持续开销）。 控件名与无障碍树随浏览器版本变化，可能失效；读不到时会自动退回标题匹配。 平时建议关着。

浏览器白名单

前台进程命中这些名字才算"在学习"。默认含 Edge / Chrome / Firefox。

        最近出现过的窗口

        在你想屏蔽的页面上停一下再切回来，它就会出现在这里。 点「取关键词」会把猜测填进上面的输入框——机器猜不准站名在哪一段，你看一眼改两个字再点添加。

          目标

          目标就是"一件有截止日的事"，不一定是考研——期末考、项目截止、任何你希望在此之前 持续投入的事情都行。名称会显示在桌宠上（如「距考研初试 99 天」）。

          应用

          关掉凤凰窗口不会退出程序——托盘图标还在，点它就能把凤凰叫回来。 真正退出请用托盘菜单里的「退出」。

          自启动建议在打包版里开启：开发态注册的是 electron.exe 加项目路径，依赖 node_modules 存在。
